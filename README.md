# Module 2: Python Mini Project — Codomax Digital Internship

**Project:** Expense Tracker
Submitted by Muhammad Waqar Tahir (BS Computer Science, GCUF)

## What it does

A command-line expense tracker built with core Python. It lets a user:

- Add an expense with amount, category, and description
- View all logged expenses in a formatted table
- See total spending and totals broken down by category
- Delete an expense by its ID
- Persist data between runs using a local `expenses.csv` file

## Files

- `expense_tracker.ipynb` — the full project, with the core functions, a demo run showing sample output, and an interactive command-line menu (commented out so the notebook runs top-to-bottom without blocking on input).

## Concepts applied

Functions, conditionals, loops, lists and dictionaries, and basic file I/O (reading/writing CSV) — building directly on the fundamentals practiced in Module 1.

## How to run interactively

Open `expense_tracker.ipynb` in Jupyter, uncomment the code in the final cell, and run all cells. Or copy that same logic into a `.py` file and run it from a terminal with `python expense_tracker.py`.
